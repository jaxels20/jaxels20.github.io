# Badminton Intelligence

Statistics site for Danish team badminton (badmintonintelligence.dk) with:

- React + Vite frontend (`frontend/`)
- FastAPI backend (`backend/`) serving a JSON API under `/api/v2` (teams, players, head-to-head, leagues, standings, matches, leaderboards)
- PostgreSQL warehouse and SQL reports (`sql/`)
